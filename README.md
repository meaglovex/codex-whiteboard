# 产品白板插件

给产品经理使用的开发前共识白板。主板保存最核心的想法、流程、视觉参考和关键交互；节点下面保留讨论依据、备选方案、分支和异常细节。人与 AI 相互提出方案、质疑和回应，形成可带入开发的共识。

## 当前交付

基础白板的本地交互视觉稿。采用 React、TypeScript、Vite 和 MIT 许可的 React Flow，保留独立项目结构。界面文案和操作组件均可编辑，森林、艺术拼贴和日常照片由内置 Imagegen 分别生成。

已实现：自由拖动节点、移动画布、缩放、连接节点、编辑想法与流程步骤、图片导入、钉住、展开多层内容、交互原型、本地自动保存、JSON 和包含下层内容的 Markdown 导出预览与复制。下载按钮请求浏览器保存文件，本轮内置浏览器没有返回下载回执。右侧是预置讨论示例；用户新增发言真实保存到本地，模型不会在这一版本自动回应。

尚未实现：真实模型辩论、宿主记忆读取、跨会话后端存储、用户账户、MCP 面板入口和插件市场提交。视觉稿里的本地保存不替代正式插件的服务端持久存储。

## 运行与交付

```bash
npm install
npm run dev -- --port 5199
npm run build
npm run preview -- --port 5200
```

`dist/index.html` 是包含脚本、样式和图像的独立 HTML，约 2.5 MB；没有外部资源标签。已通过本地 HTTP 预览验收。内置浏览器的 URL 策略禁止 `file://`，因此直接双击文件的行为尚未验收。画布内容保存于浏览器本地。换浏览器或清除存储前，先留存完整 JSON。新增图片限制为 1.8 MB；超过浏览器存储额度时，界面显示未保存并提示导出，不把失败报告成保存成功。

视觉规格见 `design/DESIGN.md`，完整概念见 `design/whiteboard-concept.png`，最终浏览器实图见 `design/whiteboard-preview.jpg`。视觉和交互检查记录见 `design/VERIFICATION.md`。

当前仓库没有配置远程。发布与插件安装需在后续阶段按明确的身份、域名和授权处理。
